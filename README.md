# Corvus

A secure, privacy-focused messaging platform built with Rust.

Corvus is currently in development.

## Tech Stack

- Rust
- Tauri
- TypeScript
- React
- Go
- SQLite

## Goals

- End-to-end encrypted messaging
- Cross-platform support
- Privacy by design
- Open-source
